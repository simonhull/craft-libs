# craft-mobile UI primitives (v1)

Generated by `UPDATE_CATALOGUE=1 cargo test -p craft-mobile`. Do not edit.

An app describes each native panel as a list of these nodes (`craft_mobile::ui`), and the shell draws them with the platform's own controls. A node says what a control is, never where it goes. Every node has an `id`, unique in its panel.

When the user changes a control, the shell sends an edit: the panel, the control's `id`, a phase (`begin`, `change`, `commit` or `cancel`), a gesture number shared by every edit of one drag, and the value. The app applies it and describes the panel again; if it rejects the edit, the control goes back to the app's value.

## `number`

A value in a range: a slider, with the value shown beside it; tap the value to type one.

**Fields:** `value` within `min`..=`max`; `step` snaps it (`null`: continuous); `unit` is `none`, `percent` (a 0..=1 value shown as 0–100 %), `pixels` or `degrees`; `enabled: false` greys it out.

**Sends:** `number` edits: `begin`, `change` while dragging, then `commit` (or `cancel`); a typed value is one `commit`.

```json
{
  "type": "number",
  "id": "opacity",
  "label": "Opacity",
  "value": 0.8,
  "min": 0.0,
  "max": 1.0,
  "step": null,
  "unit": "percent",
  "enabled": true
}
```

## `toggle`

On or off: a switch.

**Fields:** `value`; `enabled: false` greys it out.

**Sends:** one `toggle` edit, `commit`.

```json
{
  "type": "toggle",
  "id": "visible",
  "label": "Visible",
  "value": true,
  "enabled": true
}
```

## `choice`

One of several options: segmented for up to 4, a menu for more.

**Fields:** `value` is the chosen option's `id`; option ids are unique; `enabled: false` greys it out.

**Sends:** one `choice` edit with the option's `id`, `commit`.

```json
{
  "type": "choice",
  "id": "blend",
  "label": "Blend Mode",
  "value": "normal",
  "options": [
    {
      "id": "normal",
      "label": "Normal"
    },
    {
      "id": "multiply",
      "label": "Multiply"
    },
    {
      "id": "screen",
      "label": "Screen"
    }
  ],
  "enabled": true
}
```

## `section`

A titled group of other nodes; the user can collapse it.

**Fields:** `children` are any nodes; `collapsed` is how it starts.

**Sends:** nothing itself; its children send their own edits.

```json
{
  "type": "section",
  "id": "layer",
  "title": "Layer",
  "collapsed": false,
  "children": [
    {
      "type": "toggle",
      "id": "locked",
      "label": "Lock",
      "value": false,
      "enabled": true
    }
  ]
}
```

## `item_list`

Rows of items such as layers, top to bottom: tap to select, swipe to hide, long-press to rename, drag to reorder.

**Fields:** each row's `id` is the app's own and unique in the list; `depth` indents it (inside groups); `visible: null` means it can't be hidden; `reorderable` allows dragging.

**Sends:** `select`, `set_visible`, `rename` and (when reorderable) `move` edits, each one `commit`, naming rows by their `id`.

```json
{
  "type": "item_list",
  "id": "layers",
  "rows": [
    {
      "id": 2,
      "title": "Sky",
      "subtitle": "Pixel",
      "depth": 0,
      "visible": true,
      "selected": true
    },
    {
      "id": 1,
      "title": "Background",
      "subtitle": "Pixel",
      "depth": 0,
      "visible": true,
      "selected": false
    }
  ],
  "reorderable": true
}
```
